## 1. 背景与问题定义

建模类任务的输入天然欠规格。"帮我做个椅子"在 Blender 里可以指：
小板凳还是办公椅？低多边形还是写实？真实尺寸 0.45m 还是 2m？面数有没有预算（游戏资产 or 单纯渲染）？
要不要材质？要建模还是连渲染图一起出？——现状 SKILL.md 从「连接自检」直接跳「任务路由表」，
缺一个把模糊一句话规格化的入口环节，执行时全靠模型脑补，返工率高。

**目标**：在 skill 的指令输入环节前置一个「反问循环式 PRD」——
先分类任务 → 批量反问关键缺口（每问都带默认值，可"按默认"跳过）→ 产出一张结构化 PRD 卡片
（含可机验验收标准）→ 用户确认 → 才进入 MCP 执行。
**非目标**：不做通用项目管理；不给查询/检查类小任务加盘问负担；不改变现有 references 01~10 的实测结论。

## 3. 设计方案（草案——R2~R4 回来后定稿再动手写）

### 3.1 档位设计（四档：直通 / 快速 / 完整 / 无限循环）
- **直通档（不问）**：查询/体检类（"面数多少""看看法线"）、单步修改（"把这个立方体变红"）、
  用户已给足规格（有参考图/明确数值/明确风格）。
- **快速档（1 轮，1 批 ≤4 问，全带默认值）**：默认适用于一切"做个/建个/渲染个"类一句话任务。
  用户回"按默认"即收口，总开销一次往返。
- **完整档（2~3 轮，硬上限 3）**：触发条件=任务含多物体场景、或用户主动展开、或快速档回答里出现
  "随便/你看着办"以外的自相矛盾。第二轮只问第一轮暴露出的矛盾点。轮次硬上限 3 轮，
  之后必须按已有信息+默认值开工并在 PRD 卡片标注假设。完整档是"不想聊太久"用户的默认复杂路径。
- **无限循环挡（【裁定⑥】新增，用户主权档）**：**轮次无上限，退出权完全在用户**。
  - 触发（满足其一）：①用户明说（"多问我几轮""边聊边细化""无限挡"）；
    ②任务达场景级/项目级规模时 AI 可**建议**进入（用户拒绝即回落完整档）；
    ③任何档位中用户说"继续问"→ 无缝升级进无限挡。
  - 退出：用户回"开工 / 就这样 / 按这个来"任意一种 → 立即停止追问、冻结 PRD 卡片、进入执行。
    "开工"通道**永久内嵌**（AskUserQuestion 的 Other 自由输入任何时候可用）。
  - 每轮纪律与收敛机制（防"无限"变"失控"）：
    a. 每轮仍 ≤4 问、每问带默认值、**只问没问过的新信息，严禁重问**；
    b. 问题按主题渐进：前几轮定大面（风格/尺度/交付物）→ 中段抠细节（材质/灯光/相机）→
       后端收尾（验收标准细化、边界情况）；
    c. **PRD 卡片草稿每轮同步演进并展示增量**（"本轮敲定了 X/Y/Z，还剩 N 个开放点"），
       用户直观看到收敛进度；
    d. AI 观察到主要决策已齐时可提示"随时可以开工"，但**是否退出永远由用户决定**。
  - 档间流动：快速/完整 →"继续问"→ 无限挡（单向升级）；任何档 →"全按默认，开工"→ 立即坍缩进执行。

### 3.2 分型问题清单（写入 references/00-prd-intake.md）
每型 6~10 个候选问题+默认值，按型取 3~4 个进快速档：
- 建模单件：尺寸单位与绝对尺度 / 风格（low-poly·写实·风格化）/ 面数预算与用途（渲染 or 导引擎）/
  参考图 / 材质要求（素模 or PBR）
- 场景搭建：地平面与尺度锚 / 资产来源偏好（PolyHaven/PolyPizza/生成式/代码几何）/ 密度 / 氛围时段
- 材质灯光：色调与色温 / 引擎（EEVEE 快 vs Cycles 真）/ HDRI 偏好
- 渲染出图：分辨率与用途 / 相机角度与焦段 / 背景透明 or 环境 / 落盘路径
- 动画：时长与帧率 / 循环 or 单次 / 缓动
- 导出交付：格式（glb/usd/obj）/ Y-up / 是否烘修改器 / 命名规范
- 改既有场景：目标物体指代（选择器） / 允许破坏范围（可否删重）

问题语言【已裁定②】：跟随用户最近一条消息的语言（本机默认中文）；节点/引擎/格式等
专有名词一律保留英文原文（Principled BSDF、Cycles、glb……），与全部分册行文规范一致。

### 3.3 PRD 卡片（对齐 prd-driven-dev 七节，3D 特化）
```
[BMCP-PRD] 任务ID / 日期 / 分型
① 目标一句话 + 对标参考（图/链接）
② 交付物清单（网格?材质?渲染图?导出文件?）——量化写死：分辨率/格式/路径
③ 非目标（V1 不做什么）
④ 技术约束：引擎、单位、面数预算、集合与前缀（MCP_SKILL_TEST 纪律）
⑤ 验收标准 Given/When/Then 全部可机验：
   例 Given 渲染完成 When images.load 回读 Then 尺寸=1280x720 且 文件>100KB
   例 Given 导出 glb When 重新导入 Then 物体数=N 且三角面=M±10%
⑥ 边界与假设：用户没答的字段在此写明"采用默认X"（显式假设区，不脑补）
⑦ 反查雷区 3 条（借 prd-driven-dev 反查环节，执行完逐条销雷）
```

## 4. 验收标准（Given/When/Then）
1. Given 输入"帮我做个椅子" When skill 触发 Then **先出现 ≤4 问的带默认值反问批次**，
   不直接建物；用户回"按默认"后一轮内收到 PRD 卡片并开工。
2. Given 输入"场景面数是多少" When skill 触发 Then **不触发反问**，直接执行审计。
3. Given 输入"给坦克渲染一张 45 度 1920x1080 的图" When 规格已足 Then 直通档不盘问。
4. Given 用户两轮回答互相矛盾（先说写实后说 low-poly）When 第三轮 Then 只问矛盾点且总轮次 ≤3。
5. PRD 卡片 ⑤ 的每条验收标准都能映射到现有实测手段（渲染回读/scene_audit/重导入对账）。
6. **无限循环挡**：Given 用户选无限挡且连续 3 轮各追加一条新需求 When 每轮提问 Then
   每轮出现的是**未问过的新问题**且 PRD 卡片草稿逐轮演进展示；When 用户说"开工" Then
   **立即退出循环进入执行、零追问**；Given 用户从未说开工 When 第 N 轮 Then AI 不得自行
   退出循环（收敛提示可以，代做决定不行）。
7. SKILL.md ≤500 行；触发评测 20 条（15 旧 + 5 新）通过率不降。
8. **捆绑包**：assets/blender-mcp-bundle/ 内 addon.py 与 wheel 的 sha256 与官方源一致且
   记录在 SHA256SUMS.txt；ATTRIBUTION.md 含作者 Siddharth Ahuja 署名与许可信息；
   SKILL.md 有"离线安装"小节；本机 Blender 已装插件只读未触碰；若许可禁再分发则
   改为命令记录（同样算过）。

## 5. 风险与对策
| 风险 | 对策 |
|---|---|
| 过度盘问惹恼用户 | 直通档判据前置；快速档一轮收口；完整档硬上限 3 轮；每问必带默认值（"provide defaults, not menus"）；无限挡退出权在用户（设计如此）且每轮内嵌开工选项 |
| 无限循环挡永不收敛烧 token | 退出权在用户=特性非缺陷；每轮展示收敛进度与剩余开放点数；AI 可提示"可以开工"但不代做决定；每轮只问新信息的纪律保证问题池有限自然收敛 |
| 与 brainstorming"一次一问"冲突 | 有意取舍：3D 规格字段相互独立（尺寸/风格/用途无依赖），批量 ≤4 问效率更高；在分册中写明取舍理由 |
| SKILL.md 膨胀 | 增量 ≤40 行，细节下沉 00 分册；超 500 行即回砍 |
| description 改动影响触发率 | 改后重跑 evals 全集对照 |
| 反问环节拖慢小任务 | 直通档白名单覆盖查询/体检/单步修改三类高频小任务 |
