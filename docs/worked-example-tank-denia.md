## 一、硬表面（豹2A7）：无头批处理全管线

| 阶段 | 做法 | 数据 |
|---|---|---|
| blockout→中模 | 基元拼装 + 精细模块回炉 | 中模 3.9 万面 / 840 件 |
| 高模 | 细节堆量 | 1208.9 万面 |
| UV | 按功能分 36 组 + Smart UV + 同型轮组复用代表组 UV + 点阵字库实体贴花 | 17,879 面 |
| 烘焙 | 高模减面合并(3.2M)→selected-to-active | 18 张贴图（**676 倍压缩**，细节全进法线） |
| 游戏版 | PBR 材质组 + glb | 8.27MB 含内嵌贴图 |
| LOD | LOD0/50%/25%/10% + 图集合并（11 材质→1） | 进引擎标准 |
| 渲染 | OptiX + Cycles 64spp ×7 张 | 1920×1080 |

**关键实测数据**（OptiX 核实）：GPU 空闲时 OptiX 快 CPU 1.86×；但 GPU 被占（常驻浏览器
WebGL 顶 98%）时反被拖累——**开工前先 `nvidia-smi` 看底噪**；OptiX 缓存目录必须可写
（`OPTIX_CACHE_PATH` 可重指），否则每帧重编内核反而更慢。

## 二、角色（达妮娅）：绑定 + 动画 + 游戏导出

高模简化→烘焙（法线返工一次：首次法线为平图，见教训②）→绑骨→转台帧→game 导出
