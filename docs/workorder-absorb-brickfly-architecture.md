## 1. 背景

用户提供「力大砖飞——ZCode×Blender×GLM(API) 建模系统 架构设计说明书 v3.0」：以 C5 公理
（**状态所有权归 Blender，模型只能通过 report JSON 投影感知场景**）为骨架的十二机制外围智能
架构（M1 方案先行 / M2 幂等 / M3 结构化回报 / M4 四阶段隔离 / M5 三级视觉反馈 / M6 多路径
搜索 / M7 API 防幻觉 / M8 Reflexion 教训 / M9 组件复用阶梯 / M10 记忆兼容 / M11 上下文预算 /
M12 思考配额）。要求解读并吸收进 skill。

解读结论：架构自洽性成立（每机制↔约束/失败模式一一对应），且 M2/M3/M5快渲/M7 已被本会话
实测批次 A/B/C 直接背书；但**有六处与本体机实测现实冲突，吸收时必须修正**（见 §3）。

## 3. 平台修正六条（吸收的强制 diff——本单灵魂）

| # | 架构原设计 | 本机实测现实 | 修正 |
