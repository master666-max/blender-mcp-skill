# blender-mcp skill

**让 AI 直接在你开着的 Blender 里干活。**
你说需求——它在真实场景里建模、调材质、打光、出图、做动画——而且**干完会自己回头看一眼成果**，不满意就继续改，而不是丢一句"已完成"了事。

> 适用于任何支持 Agent Skills 的 AI 客户端（Claude Code / Cursor / ZCode / Codex / DeepSeek Harness 等）。
> 装上之后不需要你懂代码：你在聊天里提要求，它在你面前操作 Blender。

---

## 它能替你做哪些事

| 你说 | 它做 |
|---|---|
| "建个三层小楼，日式风格" | 先问清尺寸/风格/用途，再在场景里从体块到细节盖出来，过程中随时截图给你看 |
| "给这个模型配材质，做旧一点" | 查模型现状 → 建材质 → 试渲 → **看图** → 不满意自己调，最后给你对比图 |
| "打光出图，要黄昏氛围" | 布三点光/环境光 → 出渲染图 → 读回图片检查效果 → 交付带图 |
| "这个模型面数太多了，减到两万面" | 体检网格 → 减面 → 复查面数与形变 → 报告前后对比 |
| "从网上找个沙发模型放进场景" | 连主流免费资产库（PolyHaven / Poly Pizza / Sketchfab 等）搜索、下载、摆好 |
| "帮我把这 100 个文件批量转成 glb" | 无头模式（不开界面）批量处理，服务器上也能跑 |
| "导出给游戏引擎用" | 导出并**回读验证**（防止静默丢东西），告诉你导出了什么 |

## 特点（为什么它不是又一个"提示词合集"）

**1. 它会看自己的作品。**
每次改完，它会截图或渲染，**真的读那张图**再判断好不好——不是凭参数想象画面。光照爆了、接缝露了、比例歪了，它看得见，然后自己修。

**2. 动手之前先问清楚。**
一句话需求（比如"做个椅子"）不会闷头乱做：会按任务大小分级反问——简单任务问一两句就开工，复杂任务多确认几轮，全程有默认值不烦你。定了规格再动手，比返工便宜一个量级。

**3. "完成"必须有证据。**
交付时给的不是"我改好了"四个字，而是：渲染图 + 实际测量数据（面数/尺寸/文件清单）+ 你打开就能看到的落盘文件。说出口的每件事都有可检查的依据。

**4. 不碰你的东西。**
在你自己开着的 Blender 里干活，纪律是：只动它自己创建的物体（带固定前缀），**不碰你的相机、灯光、World 和任何已有资产**；批量操作前先存快照，出问题可回退；清理时也不会误删你的东西。

**5. 断网也能装。**
安装包（插件 + 服务端）完整内置于仓库，附带校验和，离线机器照装；不依赖去外部商店下载最新版（也就不怕上游哪天改坏了）。

**6. 一份技能，多家 AI 通用。**
主流 AI 客户端都能装（各家 skills 目录一放即可），Neovim 到 VS Code 的编辑器代理、命令行代理也都兼容。

**7. 越用越厚的知识库。**
不是一段长长的说明书，是 **14 分册的实战手册**：每一条经验都标注来源——真机实测过的、还是查资料的；踩过的坑（有些坑能把一整套工作白做）都写成了规则和检查点。另附代码积木库和节点组库，重复的东西不重写。

**8. 它被反复"挑刺"打磨过。**
这个包交给独立的检查方审了 **60 多轮**，从"这句话说的和实际做的不一致"这种细节开始，被挑出并修掉的问题 **160 多个**，每一条都有记录、有去向。并且仓库自带自检命令——你拿到包后可以一条命令验证它是不是完好的，不用相信任何口头保证。

**9. 服务器 / 自动化场景也能用。**
批量转换、每日渲染、CI 流水线——不需要人手点界面，命令行走无头模式即可。

**10. 安全默认。**
代码执行默认过白名单校验（禁文件/网络/系统调用）；连接只绑本机回环地址；遥测默认关闭；所有改动都有备份和回滚路径。

## 快速开始

**第 1 步 · 装技能**：把这个仓库的文件夹复制到你 AI 客户端的技能目录，例如：

```
ZCode:          ~/.zcode/skills/blender-mcp/
Claude Code:    ~/.claude/skills/blender-mcp/
Cursor:         ~/.cursor/skills/blender-mcp/
DeepSeek Harness: ~/.dsh/skills/blender-mcp/
```

**第 2 步 · 装 Blender 插件**：Blender → 编辑 → 偏好设置 → 插件 → 从磁盘安装 → 选
`assets/brickfly-mcp-bundle/brickfly_mcp.py` → 启用。侧栏（按 `N`）会出现面板 → 点 Start MCP Server。

**第 3 步 · 连上 AI**：按 `INSTALL.md` 里的示例，把 MCP 服务端配进客户端（Windows 一键命令已写好）；
离线安装包和依赖清单都在 `assets/brickfly-mcp-bundle/` 里。

> 详细步骤、多客户端注意事项、升级与回滚、常见故障排除：见 [INSTALL.md](INSTALL.md)。

## 包里有什么

| 目录 | 用途 |
|---|---|
| `SKILL.md` | 入口手册：开工自检、七条铁律、按需求查分册的路由表、卡死恢复流程 |
| `INSTALL.md` | 三步安装 + 多客户端路径 + 离线安装 + 疑难解答 |
| `references/00~14` | **14 分册实战手册**：需求澄清 / 场景 / 材质 / 灯光渲染 / 动画 / 几何节点 / 资产库 / 网格体检 / 参数化 / 安全与报错 / 无头 CI / 部署与安全 / 执行契约 / 建模工艺 / 视觉工作流 |
| `scripts/` | 现成骨架：建模五段式模板、场景体检、三点布光、渲染出图回读 |
| `fragments/` `nodes/` | 代码积木库与节点组库（拿来即用） |
| `assets/` | 离线安装包（插件 + 服务端，含校验和与来源说明） |
| `evals/` | 自检工具：一条命令验证完整性 + 关键规则回归 |
| `docs/` | 设计文档与实战案例 |

## 环境

- Blender **5.2 LTS**（4.x/5.x 大部分功能兼容，差异处手册内已标注）
- Windows / macOS / Linux 均可；中文界面支持（含中文界面下的坑）
- 资产库等联网功能需要网络，其余功能全部本地可用
