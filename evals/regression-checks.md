## 一键校验

```bash
py evals/run-regression-checks.py          # 逐条跑上表，输出 PASS/FAIL，全过退出码 0
```

或（Windows 双击/任意终端，不依赖 python 命令解析）：

```bat
evals\run-regression-checks.cmd
```

> **解释器要求（真实 Python）**：evals 工具是 Python 脚本，需要真实 CPython（3.11+）。
> 本机若 `python` 报 `exit 9009` 静默失败 = **Microsoft Store 占位程序**（不是脚本坏了）；
> 或别名禁用后报"不是内部或外部命令"（明确失败，好诊断）。按优先级：
> ① **`py` 启动器**（Windows 官方 launcher，本机 3.14.7）；
> ② 真实安装的绝对路径（如 `%LOCALAPPDATA%\Programs\Python\Python314\python.exe`；
>    路径会随安装漂移，用 `py -0p` 现查）；
> ③ Blender 自带解释器（跑 bpy 相关脚本时天然正确）。
> **根治**：设置 → 应用 → 高级应用设置 → 应用执行别名 → 关闭 python.exe/python3.exe，
> 并把真实 Python 目录加入 PATH（改 PATH 后**已开终端不生效，需重开**）。
